# Leave The Door Open — Clone Hero Pro Drums

Silk Sonic drum chart converted from a MuseScore/GM drum MIDI.

## Install

1. Copy the whole `Leave The Door Open` folder into your Clone Hero `Songs` directory.
2. Rescan songs in Clone Hero.
3. Play **Drums** with **Pro Drums** enabled (e-kit or Pro layout).

## Contents

| File | Role |
| --- | --- |
| `notes.chart` | Expert / Hard / Medium / Easy Pro drums |
| `song.ini` | Metadata (`pro_drums = True`) |
| `song.mp3` | Audio |
| `source_drums.mid` | Original MuseScore MIDI (reference) |

## Chart notes

- **4-lane Pro** mapping: kick / snare / Y-B-G toms + Y hat, B ride, G crash
- Sync: **74 BPM**, pickup **5/16** then **4/4**
- Accents from MIDI velocity ≥ 120
- Star Power phrases on Expert only
- Offset is `0` — nudge in Moonscraper if hits feel early/late

## Playtest checklist

- [ ] Intro pickup snare fill lines up
- [ ] Kick+crash hits at section starts
- [ ] Hi-hat 16ths feel locked to the groove
- [ ] Tom fills keep high→low motion
- [ ] SP phrases feel fair
